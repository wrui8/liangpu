Guide

几步就能用上

第一次打开可能会遇到系统安全提示，按下面的步骤操作即可。

ANDROID

手机安装

01 — 04

  1. 下载 APK

    多数机型点「下载 APK」即可（arm64-v8a）；不确定机型时，下载全机型包，里面三个包都带着。

  2. 传到手机并安装

    微信文件传输、数据线或局域网共享均可。提示「未知来源应用」时选择允许后继续，需要 Android 6.0 及以上。

  3. 填写服务器地址

    首次打开会显示「连接服务器」引导页，填写运维提供的地址，填一次后自动记住。之后可在登录页底部或「我的」页修改。

  4. 登录使用

    需与服务器处于同一内网。App 已内置内部 CA，无需在手机上安装任何证书。

WINDOWS

电脑运行

01 — 04

  1. 下载并完整解压

    下载 liangpu-windows-0.1.0.zip，右键「全部解压缩」。不要直接在压缩包里双击运行，也不要只把 exe 拷出来。

  2. 双击运行

    打开解压后的文件夹，双击 良扑.exe。必须一起保留 data 文件夹和同目录全部 DLL，缺少时会弹出明确提示。

  3. 处理安全提示

    若出现「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」；来自聊天工具的文件，可先右键 zip → 属性 → 勾选「解除锁定」再解压。

  4. 登录使用

    首次启动同样会引导填写服务器地址（请向运维获取），之后可在登录页底部或「我的 → 服务器地址」修改。

IOS

iPhone / iPad 安装：先用电脑签一次名

iOS 15+

苹果不允许直接安装未签名的 App，所以 iPhone 需要先用你自己的 Apple ID 在本机签一次名。 这一步需要一台电脑配合（Windows 即可，只需一次）；推荐用 AltStore：签完之后只要手机连办公室 WiFi， 每 7 天会自动续签，平时不用再插电脑。手机上直接点下载的 ipa 只会存进「文件」，无法直接安装。

AltStore 内网源（推荐）
在 AltStore 的 Browse 页右上角点 +，填入 http://10.28.13.214/download/altstore.json； 添加后直接在源里点「良扑 → Install」，以后有新版本也在这里点 Update。

方法 A · AltStore 自动续签

推荐

一次性装好，之后在办公室 WiFi 下自动续签，不用每周插线。

  1. 电脑装工具

    Windows 安装苹果官网版 iTunes 与 iCloud（不要用 Microsoft Store 版），再安装 AltServer（altstore.io）。

  2. USB 连上 iPhone

    手机弹出「要信任此电脑吗」点信任，并输入锁屏密码。

  3. 安装 AltStore

    任务栏托盘 → AltServer 图标 → Install AltStore → 选择你的 iPhone → 输入你的 Apple ID（建议用 App 专用密码，见下方安全提示）。

  4. 手机授权

    设置 → 通用 → VPN与设备管理 → 信任你的 Apple ID；iOS 16 及以上再进入 设置 → 隐私与安全性 → 开发者模式 打开并重启手机。

  5. 安装良扑

    手机打开 AltStore → 按上面的源地址添加内网源 → 点「良扑 → Install」；也可以先在 Safari 下载 ipa，再在 AltStore「My Apps」里点 + 选中它。

  6. 首次打开

    允许「本地网络」→ 服务器地址填 10.28.13.214:7001 → 用你的账号登录。

  7. 之后自动续签

    手机与运行 AltServer 的电脑（就是这台内网服务器）在同一 WiFi 时，AltStore 会每 7 天自动续签；偶尔失败，打开 AltStore 点一下 Refresh 即可。

  8. 有新版本时

    在 AltStore 内网源里点 Update，或重新下载 ipa 覆盖安装；聊天与评分数据不会丢。

方法 B · Sideloadly 单次安装

不装 AltServer 时用；每次 7 天到期后要再插一次电脑。

  1. 电脑装 Sideloadly

    先装苹果官网版 iTunes，再从 sideloadly.io 下载 Sideloadly。

  2. 连手机并拖入 ipa

    USB 连上 iPhone 并信任电脑，把下载好的 ipa 拖进 Sideloadly，填自己的 Apple ID，点 Start。

  3. 信任描述文件

    设置 → 通用 → VPN与设备管理 → 信任你的 Apple ID；iOS 16 及以上再打开开发者模式并重启。

  4. 7 天后重签

    到期 App 打不开时，用同一个 ipa、同一个 Apple ID 再走一遍即可覆盖安装，数据保留。

安全提示 Apple ID 只在你自己的电脑上用于本机签名，不经过良扑服务器。不放心可到 appleid.apple.com 生成一个 App 专用密码 填给 Sideloadly / AltServer。 免费 Apple ID 同一时间最多 3 个自签 App，每个 7 天有效；到期 App 打不开属于正常现象，按上面步骤续签即可。
演示账号 普通用户 demo / demo123；管理员账号请向部署同事索取。登录状态保留 7 天，过期后重新登录即可。
FAQ

常见问题

安卓手机应该下载哪个包？

绝大多数手机下载 arm64-v8a 那个即可。老旧 32 位手机用 armeabi-v7a，安卓模拟器用 x86_64；分不清就下载「全机型包」，三个 APK 和安装说明都在里面，试其中一个能装就用它。

iOS 版怎么安装？

本站提供的是云端构建的未签名 IPA，iPhone 不能直接安装，需要先用你自己的 Apple ID 在本机签一次名。推荐用 AltStore（Windows 电脑一次性安装，之后只要和办公室 WiFi 里的 AltServer 同网，就会每 7 天自动续签）；不想装 AltServer 就用 Sideloadly，每次到期后重新插一次电脑。完整步骤见「iPhone / iPad 安装」。

iPhone 上直接点下载的 ipa 能装吗？

不能。iOS 只接受带有效签名的 App，未签名 ipa 点开后只会保存到「文件」App，不会出现安装或「信任」按钮。必须借助电脑（Sideloadly / AltStore）用 Apple ID 重签；如果想让同事点个链接就装好，需要公司申请苹果开发者账号（Ad Hoc 或 TestFlight）。

为什么 7 天要续签一次？

免费 Apple ID 的签名有效期是 7 天，到期后 App 打不开、图标变灰都属于正常现象，不是安装包坏了。用 AltStore 续签不需要重新下载 App，聊天、评分、登录状态等数据都不会丢；同一时间免费账号最多保留 3 个自签 App。

AltStore 续签失败 / 图标变灰怎么办？

先确认手机和运行 AltServer 的电脑在同一个 WiFi、电脑没有关机或睡眠，然后打开 AltStore 点一下 Refresh；仍失败就把手机用 USB 连回电脑，在 AltServer 托盘菜单里重新 Install AltStore，再在 AltStore 里更新良扑。iOS 16 以上如果没有打开「开发者模式」，App 也会打不开，需要在 设置 → 隐私与安全性 里开启并重启。

没有电脑能装 iOS 版吗？

不能，苹果要求每台设备用自己的账号签名。完全不用电脑的安装方式（Safari 点链接直接装、或 TestFlight 点邀请）都需要付费的苹果开发者账号，需要的话可以让运维申请后统一分发。

手机打开本页需要安装证书吗？

不需要。本页是独立的公开下载入口，使用普通 HTTP 服务，任何手机浏览器（包括微信内置浏览器）都能直接打开并下载安装包。HTTPS 与内部 CA 只用于 App 和服务器之间的通信。

安装 App 后提示证书校验失败？

说明使用的是旧版安装包。请从本页重新下载最新 APK 覆盖安装，不要使用聊天记录里旧版本的文件。

提示无法连接服务器？

请确认设备与服务器在同一内网，并向运维确认服务器地址，检查登录页底部或「我的 → 服务器地址」是否填写正确。地址变更后需要改用新地址。

双击「良扑.exe」后没反应？

先确认文件夹里有没有 data 子文件夹。只拷贝 exe 和 DLL 时程序无法启动，会弹出「缺少 data 文件夹」提示。请重新把 zip「全部解压缩」后运行；若点击「运行」后一直无窗口，检查 360 / 火绒等安全软件是否拦截，并把整个文件夹加入信任。

给员工打分后，团队评分会变化吗？

会。团队分 = 团队直接评分 + 该团队全部员工评分的合并平均。给任意员工打分后，团队卡片和详情页的分数、评分人数、十档分布会立即重算；返回团队页或下拉刷新即可看到结果。

能不能发给多台电脑使用？

可以。把解压后的整个文件夹复制给对方即可，登录时用自己的账号。请勿只拷贝 良扑.exe，必须带上 data 文件夹和 DLL。

登录多久会过期？

登录状态有效期为 7 天，过期后输入账号密码重新登录即可，评分与评论都会保留。

怎么发布动态？能看到别人的动态吗？

登录后进入底部「动态」页，点右上角「发布」即可写文字、选图片（最多 4 张，自动压缩后上传）。平台动态按点赞量和发布时间排序；点卡片右下角「评论」可进入详情参与讨论，点任意头像可进入该用户主页查看其发布的全部动态。图片保存在内网服务器上。

消息红点是什么意思？

首页右上角铃铛显示未读消息数。你的评论或回复被点赞、被回复，或你发布的动态被点赞、被评论时会产生通知；自己操作自己不会通知。点开铃铛进入消息中心会自动标记已读，点击任意一条可跳转到对应详情，未读数约 30 秒自动刷新。

怎么回复别人的回复？回车会发送吗？

每条回复右下角也有「回复」按钮，点它即可继续回复，内容显示「A 回复 @B」，同级平铺不会越缩越窄。评论、回复弹窗与打分短评支持 Enter 直接发送、Shift+Enter 换行；手机端使用键盘上的「发送」键。

评分和评论存在哪里？

全部保存在内网服务器的数据库中，不经过任何公网服务，抓包也看不到账号、评分、评论与动态图片。

管理端提示「您的连接不是私密连接」怎么办？

管理后台使用内部证书，每台管理电脑首次访问需安装一次： 下载 管理端证书安装包， 解压后双击 安装证书.cmd，看到「证书已安装」即可（无需管理员权限）。 装完完全关闭浏览器再重新打开。
